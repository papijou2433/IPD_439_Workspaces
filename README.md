# IPD_439_Workspaces
Repositorio para subir tareas y proyectos pertenecientes al ramo IPD439: Seminario Avanzado de Computadores de la Universidad Técnica Federico Santa María

Para poder replicar los resultados del trabajo realizado debiese bastar con clonar este repositorio e inicializar el STMCubeIDE en el workspace correspondiente. En el caso de la Tarea 1, este workspace corresponde a ./T1
